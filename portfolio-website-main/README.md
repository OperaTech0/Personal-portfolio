# Interactive 3D Developer Portfolio

Welcome to my professional portfolio—an immersive, interactive 3D experience designed to showcase my journey as a software engineer. Moving away from traditional flat layouts, this site invites users to explore my work within a virtual 3D space.

##  The Vision

This project was built to demonstrate the intersection of modern web development and 3D graphics. By leveraging the power of **React Three Fiber** and **Framer Motion**, I've created a dynamic interface where my projects aren't just listed; they are part of a responsive, animated environment.

##  Technical Stack

*   **Core:** [React.js](https://reactjs.org/)
*   **3D Engine:** [Three.js](https://threejs.org/) via [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
*   **3D Utilities:** [Drei](https://github.com/pmndrs/drei) (Camera controls, 3D Text, and Image components)
*   **Animations:** [Framer Motion 3D](https://www.framer.com/motion/3d/) for smooth, physics-based transitions.
*   **State Management:** [Jotai](https://jotai.org/) for atomic, lightweight project navigation state.

##  Key Features

*   **3D Project Carousel:** A cinematic navigation system where project cards transition with realistic depth and rotation.
*   **Immersive User Interface:** A spatial UI that prioritizes engagement and visual storytelling.
*   **Graphics Gallery:** A dedicated visual showcase for brand identity and UI/UX design work.
*   **Dynamic Highlighting:** Real-time visual feedback (opacity and scale shifts) when hovering or selecting specific projects.
*   **Smart Contact System:** A modern contact form with real-time validation, automatic **WhatsApp redirection**, and professional EmailJS integration.
*   **Interactive Character:** A 3D avatar that follows your journey, dynamically adjusting its position and scale to match the content of each section.

##  Featured Projects

The following projects are showcased within the immersive scene:

## 🏁 Getting Started

To explore the project locally, ensure you have [Node.js](https://nodejs.org/) installed.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/OperaTech0/Personal-portfolio.git
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Launch the development server:**
    ```bash
    npm run dev
    ```

## 🕹️ Controls

*   **Navigation:** Browse the project carousel via the UI (built with Jotai atoms).
*   **Interaction:** Click on any project card in the 3D scene to open the live link in a new tab.
*   **Contact:** Messages sent via the contact form are delivered to email and automatically pre-filled in WhatsApp for immediate follow-up.
*   **Custom Cursor:** The cursor dynamically adapts its style when hovering over interactive elements.
